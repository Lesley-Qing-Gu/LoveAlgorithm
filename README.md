# ASTA – LoveAlgorithm 💜

ASTA LoveAlgorithm is a personality-based relationship matching system inspired by MBTI-style questionnaires.

Users answer a set of questions, are classified into relationship types, and are matched based on type compatibility.

---

## Features

- Questionnaire-based personality typing  
- MBTI-like relationship type system  
- Compatibility calculation  
- Match result with brief explanation  

---

## How It Works

1. User completes the questionnaire  
2. System generates a relationship type  
3. Algorithm compares two types  
4. Compatibility score and explanation are shown  

---

## Tech Stack

- Frontend: Vue / React  
- Backend: Node.js / Firebase  
- Algorithm: Rule-based type matching
